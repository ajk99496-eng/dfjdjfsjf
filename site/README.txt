LIGHT LAB · 고등학교 이산 수학 프로젝트형 평가
=============================================

1. 실행 방법
- index.html 파일을 Chrome, Edge, Firefox에서 엽니다.
- 인터넷 연결 없이 사용 가능합니다. (온라인 글꼴은 연결이 끊기면 시스템 글꼴로 대체됩니다.)
- index.html, style.css, app.js를 같은 폴더에 둡니다.

2. 학생 활동
- AND / OR / NOT / 스마트 조명 미션 중에서 선택합니다.
- 왼쪽의 게이트를 클릭하거나 캔버스로 끌어다 놓습니다.
- 포트 연결: 출발 노드의 오른쪽 원형 출력 포트 → 목적지 노드의 왼쪽 원형 입력 포트.
- 스위치 A/B/C를 켜고 끄며 실험하고 '8가지 조건 검증하기'를 누릅니다.
- 오류를 수정하며 검증 과정을 반복하고 성찰 기록을 작성합니다.
- '평가 기록 내려받기'로 JSON 원본, '검증 기록 CSV'로 시도 결과를 저장합니다.

3. 데이터와 평가 유의점
- 서버, 회원가입, 개인정보 자동 수집, 외부 전송, 자동 모둠 통합 대시보드가 없습니다.
- 팀 코드와 작업 기록은 현 브라우저의 localStorage에 임시 저장됩니다.
- 브라우저 데이터 삭제 시 사라질 수 있으므로 JSON 파일을 내려받아 제출하도록 안내합니다.
- 자동 검증은 진리표 일치 여부 8/8만 판단하며, 최종 점수(100점)는 교사 루브릭에 따라 부여합니다.
- 프로젝트형 과제 안내문과 채점 기준은 docs 폴더의 별도 파일을 확인하세요.
- 다양한 다른 논리 회로도 같은 진리표이면 정답으로 인정합니다.

4. 제작 범위
- 논리값 시뮬레이션입니다. 전압이나 실제 회로 안전성, 소자 지연은 모델링하지 않습니다.
- 회로 파일(JSON)을 다시 불러올 수 있습니다. CSV는 개별 모둠별로만 출력됩니다.

5. 평가 기준 출처
- 교육부 고시 제2022-33호 [별책 20], 이산 수학 성취기준 [12이수03-04].
